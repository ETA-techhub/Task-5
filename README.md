# 🌳 Task 5: Decision Trees & Random Forests - Heart Disease Dataset

## ✅ Objective
Train and evaluate decision tree and random forest models on heart disease classification.

## 🛠 Tools Used
- Python (Google Colab)
- Pandas, Matplotlib, Seaborn
- Scikit-learn (DecisionTreeClassifier, RandomForestClassifier, cross_val_score)

## 🔍 Steps Followed

1. **Data Preprocessing**:
   - Used Heart Disease dataset (from Plotly's repo)
   - Split into training and testing sets

2. **Decision Tree Classifier**:
   - Trained with limited depth to control overfitting
   - Visualized using `plot_tree()`

3. **Random Forest Classifier**:
   - Trained and compared to decision tree performance
   - Feature importances visualized

4. **Evaluation Metrics**:
   - Confusion Matrix, Accuracy, Classification Report
   - 5-fold Cross-validation for Random Forest

## 📈 Output
- Accuracy Scores
- Tree Visualization
- Feature Importance Chart
- Cross-validation stats
